# Odoo Tricorder 0.3.0 — Intentions, plan et exécution

Cette version rend visibles les demandes avant leur planification et suit le travail du principal et de ses agents dans une interface commune.

## Ce qui change

- **Intentions → Plan** : demande originale, décisions, historique et liens vers les tâches.
- Nouvelles demandes affichées **À préciser / À planifier** dans le Plan et les deux Kanbans. Détection des changements toutes les deux secondes, sans bouton Actualiser.
- Graphe de dépendances avec navigation clavier et alternative en liste.
- Carte d’orchestration, activités simultanées, filtre En exécution et timers des étapes observées.
- Réception historique conservée même quand une preuve doit être contrôlée à nouveau.
- Lancements Codex/Claude instrumentés, logos OpenAI/Anthropic, interface compacte et libellés harmonisés.
- README réorganisé et [exemples de parcours illustrés](../WORKFLOWS.md).

## Installer ou mettre à jour

Télécharger le paquet `.deb` et `SHA256SUMS` dans les pièces jointes de la [release GitHub](https://github.com/le-goff-benoit/odoo-tricorder/releases/tag/v0.3.0), puis :

```bash
sha256sum -c SHA256SUMS
sudo apt install ./odoo-tricorder_0.3.0_amd64.deb
```

Paquet Ubuntu amd64. Après la mise à jour, fermer puis rouvrir la fenêtre pour charger la nouvelle interface. La fermeture de la fenêtre conserve les shells ; arrêter un onglet reste une action explicite.

Les nouvelles fonctions de planification nécessitent [Odoo Crew v2026.09.15](https://github.com/le-goff-benoit/odoo-crew/releases/tag/v2026.09.15) ou ultérieur. Dans la copie de Crew : `git pull --ff-only`, puis `./build.sh`. Révision utilisée par la CI : `4c6738c60c959fd1ceac7d24d6949d96909b6ab2`.

## Quotas et modèles

Les adaptateurs de quotas sont expérimentaux : les quotas natifs réels n’ont pas pu être qualifiés sur le poste de validation. Une valeur absente reste indisponible, jamais zéro. Les modèles légers restent expérimentaux ; le principal est conservé par défaut. La continuation a été vérifiée avec un parent ouvert, sans mécanisme de réveil d’une session fermée.
