# 0.3.5 — Une identité : LCARS discret

Trois directions ont été maquettées (`docs/design/variants/`) : LCARS discret,
passerelle d’opérations, instrument de terrain. La première est retenue, avec deux
emprunts à la seconde. Le raisonnement est dans `docs/design/DIRECTION.md`.

## Ce qui change à l’écran

- **Typographie** : Antonio (condensée, capitales espacées) pour la marque, le
  nom du projet, les titres de section, les onglets, les segments, les en-têtes
  de colonnes et les badges ; IBM Plex Sans pour le texte ; IBM Plex Mono pour les
  identifiants, séries, minuteurs et compteurs. Polices embarquées, aucun
  chargement réseau.
- **Palette** : noir chaud, texte crème, sable pour l’action et l’en-cours,
  sauge pour le confirmé et l’activité observée, prune pour l’orchestration, ciel
  pour l’information, rose pour les blocages.
- **Signatures LCARS** : rail latéral segmenté, coude sable sous le nom du projet,
  capuchon en tête de chaque titre de section, capuchon coloré par état devant
  chaque ligne de tâche. Rien de plus.
- **Contrôle sur l’exécution** : les onglets portent leur numéro (= raccourci Alt),
  chaque tâche affiche un rail d’étapes du workflow (parcourue, en cours, à venir),
  les minuteurs des activités sont posés dans une pastille monospace.
- Marque « Tricorder · NCC · version » dans la barre latérale ; état vide du
  terminal sur le glyphe de l’application.

Contrôles locaux : 87 tests Python, 56 tests Node, 16 parcours Electron réussis
(1 test de projet réel volontairement ignoré), mêmes parcours dans le paquet et
construction Debian réussie.
