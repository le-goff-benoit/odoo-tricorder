# Tricorder 0.4.1 — Ouverture des releases riches en mémoire

Les contributions d’implémentation réutilisent la validation du plan pendant
une même lecture de Mémoire. Chaque actualisation recalcule les preuves avec
le validateur Crew. Cela évite le dépassement du délai d’ouverture de 60 secondes
sur les releases comportant de nombreuses contributions.

La release NECA signalée passe de 61 secondes à environ 9 secondes dans le
lecteur, avec ses 11 tâches et 135 contributions accessibles.

Validation : 97 tests Python, 59 JavaScript, 18 parcours Electron sur sources
et paquet, ainsi qu’un parcours supplémentaire sur NECA en lecture seule.
Les empreintes des fichiers de la release sont conservées. Paquet Debian
préparé et installé localement.
