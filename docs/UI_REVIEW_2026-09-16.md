des blocs, vues et sous-vues. Direction artistique conservée.

## Couverture de la revue

| Vue | Blocs et sous-vues parcourus |
| --- | --- |
| Cadre global | Rail, projets, activité, sélection projet/release/environnement, raccourcis et onglets |
| Terminal | État vide, session synthétique, onglets, recherche, contexte, conservation du processus lors de la navigation |
| Intentions | Liste, demande sélectionnée, source conservée, historique, décisions, contraintes et liens vers les tâches |

| Projet → Fichiers | Racine, dossier de release, navigation parent, catégorie active, recherche transversale et résultat |
| Projet → Sources | Bibliothèques, modules, intégrité, dépendances, profil local du projet |
| Projet → Environnements | Cartes, avertissement production, sélection de contexte, état de la stack et configuration |
| Dialogues communs | Préférences et raccourcis dépliés, skills et commande préparée, quotas indisponibles, À propos, Markdown et source brute |

Les tests utilisent des projets synthétiques. Les vues principales sont vérifiées
à 1440 × 900, 1000 × 900 et 1000 × 700 avec zoom 125 %. Le nouveau parcours de
sous-vues couvre grand écran et zoom 125 %, contrôle les débordements, les titres
accessibles, la fermeture visible et le retour au clavier. Les tableaux, graphes
et blocs de code peuvent défiler dans leur zone dédiée.

## Validation

- `npm test` : 87 tests Python et 57 tests JavaScript réussis.
- `npm run test:ui` : 17 parcours réussis ; le parcours facultatif sur projet réel
  reste désactivé. Aucune donnée client nécessaire pour cette passe.
- `npm run dist` : paquet Debian construit.
- `npm run test:packaged` : 17 parcours réussis, 1 facultatif ignoré, sur le
  binaire empaqueté ; les polices embarquées se chargent réellement.
- Dernière retouche de placement de la fermeture : parcours UI review rejoué
  depuis les sources puis sur le binaire final reconstruit : réussi dans les
  deux cas (fermeture visible et maintenue à droite).
- `git diff --check` et vérification syntaxique des JavaScript modifiés : verts.
- Captures des parcours dans `test-results/` ; sélection conservée dans
  `ui-review-2026-09-16/`.

La revue couvre les vues et les états exercés ci-dessus ; elle ne prétend pas
simuler toutes les combinaisons de données ou les fenêtres natives du système
(sélecteur de fichiers, lecteur PDF externe). Aucun changement de règles métier,
publication ou installation sur le poste dans cette intervention.
