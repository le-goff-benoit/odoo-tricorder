# Marques des fournisseurs

Les logos servent à identifier les services dans le cockpit. Ils restent la
propriété de leurs titulaires respectifs ; aucune affiliation n’est revendiquée.

- OpenAI : monoblossom blanc, pack officiel [OpenAI Logos 2025](https://cdn.openai.com/brand/OpenAI-Logos-2025.zip), [directives](https://openai.com/brand/).
- Anthropic : monogramme de la navigation mobile du [site officiel](https://www.anthropic.com/), extrait le 15 septembre 2026.

`src/provider-brand.mjs` reprend les tracés et proportions des SVG locaux,
sans requête réseau à l’exécution. La version OpenAI blanche garde sa couleur.
